## Requisitos obligatorios

| ID | Requisito |
|---|---|
| REQ-001 | Estructura HTML5: `<!DOCTYPE html>`, `<html lang>`, `<head>`, `<meta charset="UTF-8">`, metadatos para móviles, `<title>` y `<body>` en cada documento. |
| REQ-002 | Semántica HTML5: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure` y `figcaption`, según su significado. |
| REQ-003 | Encabezados y texto: jerarquía coherente de `h1` a `h3`, y uso de `p`, `strong`, `em`, `blockquote` y `small`. |
| REQ-004 | Listas: `ul`, `ol` y `li`; recomendado `dl`, `dt` y `dd`. |
| REQ-005 | Tabla semántica con `caption`, `thead`, `tbody`, `tr`, `th` y `td` (y `tfoot` si procede), con datos tabulares reales. |
| REQ-006 | Formulario con `form`, `label`, `input`, `textarea`, `select`, `option`, `button`, `fieldset` y `legend`; tipos de entrada adecuados, `required` y validación nativa, sin simular envíos. |
| REQ-007 | Multimedia funcional: `img`, `audio` y `video`, con `source`, `track`, `figure` y `figcaption`; sin reproducción automática con sonido. |
| REQ-008 | Al menos dos documentos HTML (objetivo: cuatro) enlazados entre sí. |
| REQ-009 | Sintaxis correcta: etiquetas cerradas, anidamiento válido, atributos correctos, IDs únicos, referencias existentes y validación formal. |
| REQ-010 | Originalidad y autoría: distinguir código propio, recursos reutilizados, bibliotecas externas y código asistido por herramientas. Máximo 50 % de código de terceros. |
| REQ-011 | Ortografía y redacción revisadas en todo el texto en español (penalización de dos puntos por error). |
| REQ-012 | Referencias en formato APA 7, sin datos inventados. |
| REQ-013 | Entrega: repositorio de GitHub y archivo ZIP de respaldo con el nombre `cedula_nombre.zip`. |
| REQ-014 | Video explicativo de 10 minutos como máximo, con código y funcionamiento reales. |
